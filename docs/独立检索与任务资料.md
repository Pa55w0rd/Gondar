# 独立检索与任务资料

系统设置的“搜索来源”可选择“DeepSeek Search/Fetch（独立API）”，单独填写密钥并保存，再按各Agent的搜索开关启用。该密钥只写入配置，不回显，也不会从当前聊天模型借用。原“模型内置搜索”选项继续兼容。

独立搜索返回可引用的标题、链接和摘要，SearchFetch用于公开参考正文。公开文档URL交给第三方服务抓取；需要登录态的目标、内网与携带凭据的URL应使用既有目标访问工具。服务端抓取不等于本地MITM已留痕，检索材料也不等于执行过安全测试。

官方接口为[网页搜索](https://api-docs.deepseek.com/zh-cn/api/search/)和[网页抓取指南](https://api-docs.deepseek.com/zh-cn/guides/search/)。本项目使用合成HTTP校验协议、鉴权、取消、错误和大小边界，真实账号可用性及费用以服务方实际回执为准。

任务资料来源在任务设置中选择。旧默认“授权范围内资料”保持兼容；“仅本任务与直接来源资料”只改变可用于新工作的资料集合，始终与已有范围求交。关联资料、同根域、共享IP与历史证据不自动增加授权。历史事实、报告和附件仍可核对。

任务详情“任务文件”提供只读浏览。最近文件最多扫描1万条、深度32并有独立时间预算，结果截断会明确提示。目录ZIP最多2000条目、256MiB、同时2个作业；运行中目录不是事务快照，文件变化或读取失败会中断导出。请进入较小子目录导出超限内容。
