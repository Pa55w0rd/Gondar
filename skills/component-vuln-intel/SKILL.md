# 组件线索核验卡

记录版本证据来自包、构建信息、响应还是推测；核对官方公告、修复提交与发行范围，注意发行商回补补丁及前置配置。

将“版本在范围内”“危险路径可达”“实际影响已证实”分开。先核已有流量、源码与配置，再在任务授权条件下进行最小复测；无适配协议或环境时只登记线索。

修复验证需要修复前后对照与相关回归。不可达、认证失效或测试工具失败不是已修复证据。引用固定版本/提交/实际活动编号，避免重复派发相同假设。
