# 源码审计卡

确认仓库路径、版本、入口与依赖。先通过当前可用的搜索工具定位，再阅读上下文，记录“输入→转换/校验→调用链→危险操作”。检查框架绑定、权限、编码及配置条件，字符串命中不等于可达漏洞。

将代码假设与运行验证分开：无运行环境时明确条件，不能编造执行结果。构造复现只使用任务授权的本机或隔离环境，不因源码里出现域名就访问它。

逐模块记已检查、未检查与原因，避免一次把整仓或大型参考文库塞进上下文。工具/文件缺失时记录缺口；跨语言、移动端或合约专用工具未配置时，不声称完成对应动态分析。
